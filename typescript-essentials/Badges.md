## Reflections

**Module 1**
Provides the very basic information about Typescript. But also explains why it's necessary to use in real-life profects. Gives a clear idea of advantages of Typescript in comparison with JS.

**Module 2**
Very good opportunity to go deeper into types. Represents the primitive types existing in JS and widens them with absolutly new possibilities like enums or union types for example. Also gives the knowledge about combining different types with the help of intersection types. Explains clearly why it's important and beneficial to define types. And gives understanding how to avoid errors during the run-time. 

**Module 3** 
Helps to understand how to work with objects in TypeScript. And provides you with opportunity to extend already exsisting interfaces which turn it into reusable components. Also allows you to define the properties with their type (required, optional, read only) which again prevents from unexpected errors. 

**Module 4** 
This module gives an overview on functions: how to declare them in TypeScript and how to work with them. TypeScript simplifies the development of functions and makes them easier to troubleshoot by enabling you to type parameters and return values. Adding types to functions helps prevent you from passing values that you shouldn't pass to your functions. TypeScript also gives the opportunity to set parameters as requiered, optional or default.

**Module 5**
As in JS TypeScript provides you with opportunity to work with classes. It allows to set properties, constructor, accessors and methods. In TypeScript, you can control the visibility of class members by adding the public, private, or protected keyword before the member name. It allows to control the access to class members and prevents reaching them from the outside when you don't need it. Here you can also create static properties and methods which are shared by all instances of the class. 

**Module 6**
Generics are the powerful tools which allow to create a component that can work over a variety of types rather than just one. What is more it's possible to use multiple type variables. When using type variables to create generic components, you may only use the properties and methods of objects that are available for every type. This prevents errors from occurring when you try to perform an operation on a parameter value that is incompatible with the type that's being passed to it. 

**Module 7** 
This module gives an idea of exporting and importing modules in TypeScript which makes code better-orginized and reusable. It can also be implemeneted on project and reduces the necessaty to write the same things several times. 

**Module 8** 
Namespaces are another way in a TypeScript to organize and categorize a code, enabling to group related code together. This placement can help you avoid naming conflicts between components in the global namespace and can be beneficial when working with distributed development teams that may use similar component names. It serves almost the same aim as modules does and also allows allow you to group variables, functions, interfaces, or classes related to business rules in one namespace and security in another.
